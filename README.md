# Lista de Tarefas
Sistema de gerenciamento de tarefas desenvolvido em **Python**, utilizando SQLite para armazenamento dos dados cadastrados.

## Descrição
Este projeto foi desenvolvido para praticar conceitos de programação em Python e integração com banco de dados SQLite.

O sistema permite cadastrar, listar, concluir, editar e excluir tarefas por meio de uma API desenvolvida com flask.

## Funcionalidades
* Adicionar tarefas
* Listar tarefas
* Concluir tarefas
* Editar tarefas
* Excluir tarefas
* Armazenamento local utilizando SQLite
* Identificação das tarefas por ID
* Controle de tarefas pendentes e concluídas
* API REST em Flask
* Recebimento e envio de dados com JSON

## Tecnologias utilizadas
**Linguagem:** Python - Versão 3.14.7.  
**SGBD:** SQLite.  
**Framework:** Flask.  
**Linguagem de consulta:** SQL.  

## Estrutura CRUD
* **Create** - Adicionar tarefas
* **Read** - Listar e buscar tarefas
* **Update** - Editar e concluir tarefas
* **Delete** - Deletar tarefas

## Como usar

</div>

<div style="border: 1px solid #30363d; border-radius: 10px; padding: 20px;">

### 1. Acesse o arquivo `app.py`

Abra o projeto no seu editor de código e localize o arquivo:

```text
app.py
```

### 2. Execute o sistema

No terminal, dentro da pasta do projeto, execute:

```bash
python app.py
```


### 3. Acesse a aplicação

Após executar o `app.py`, o Flask iniciará o servidor local.

No terminal será exibido o endereço da aplicação. Normalmente:

```text
http://127.0.0.1:5000
```

Abra esse endereço no navegador para utilizar a API.
