# Lista de Tarefas
Sistema de gerenciamento de tarefas desenvolvido em **Python**, utilizando SQLite para armazenamento dos dados cadastrados.

## Descrição
Este projeto foi desenvolvido para praticar conceitos de programação em Python e integração com banco de dados SQLite.

O sistema permite cadastrar, listar, concluir, editar e excluir tarefas.

## Funcionalidades
* Adicionar tarefas
* Listar tarefas
* Concluir tarefas
* Editar tarefas
* Excluir tarefas
* Armazenamento local utilizando SQLite
* Identificação das tarefas por ID
* Controle de tarefas pendentes e concluídas

## Tecnologias utilizadas
Linguagem: Python - Versão 3.14.7. 
SGBD: SQLite

## Objetivo
Projeto desenvolvido com finalidade de estudo e prática de conceitos como funções, condicionais, estruturas de repetição, tratamento de erros, SQL e operações CRUD.
